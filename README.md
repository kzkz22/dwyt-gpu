# dwyt-gpu

A **dwyt** GPU-gépe: NVIDIA GPU-s gépre (Linux + Docker, Windows WSL2-vel) a llama-server és a Whisper GPU-worker (WhisperX, igazítás, beszélőfelismerés) konténere, a modellek NVMe-gyorsítótára és egy modellletöltő parancs. Igény szerint fut: az AI-router ([dwyt-airouter](https://github.com/kzkz22/dwyt-airouter)) indítja és állítja le.

- Terv és döntések: [dwyt-docs/docs/terv.md](https://github.com/kzkz22/dwyt-docs/blob/main/docs/terv.md) (10. fejezet)

## Állapot

Terv; kód még nincs. A régi `yt-transcribe` GPU-workeréből nő ki.
